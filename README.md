# DigitalClock_CourseDesign

一个基于 FPGA 的数字时钟课程设计小项目。实现了基本的时、分、秒计时与显示，支持时间设置、闹钟设置、整点报时与闹铃提醒，并可播放《把回忆拼好给你》的部分旋律。整体定位是一个偏入门的小玩具项目，适合作为数字逻辑 / FPGA 课程的练手参考。

> 说明：作者并非硬件方向，设计没有做得太深入，重在跑通基本功能，欢迎交流指正。

---

## 功能特性

- **基本计时**：时、分、秒正常走时，支持 24 小时制显示
- **时间设置**：可手动调整时、分、秒
- **闹钟设置**：可设定闹钟时间
- **到点报时**：到达设定时间触发提醒
- **闹铃功能**：闹钟触发时发出提示音
- **音乐播放**：可播放《把回忆拼好给你》的部分音调
- **数码管显示**：时分秒映射到开发板数码管上显示

## 工作原理简述

1. **时钟分频**：将板载晶振时钟分频得到 1Hz 信号，用于秒计数。
2. **计时模块**：秒计数满 60 进位到分，分满 60 进位到时，时满 24 归零。
3. **显示模块**：通过动态扫描方式将时、分、秒输出到数码管。
4. **设置模块**：按键切换设置状态，调整时、分、秒及闹钟值。
5. **闹钟比较**：当前时间与闹钟时间一致时，触发蜂鸣器报时。
6. **音乐播放**：用分频产生的不同频率驱动蜂鸣器，按预设音符序列播放旋律。

## 使用方法

1. 使用 Quartus / Vivado 等工具打开工程。
2. 根据你的开发板修改引脚约束文件。
3. 综合、布局布线并下载到 FPGA 开发板。
4. 上电后数码管显示当前时间，通过按键进行时间与闹钟设置。

---

## 按键说明

| 按键 | 功能 |
|------|------|
| KEY1 | 切换设置模式（正常 / 调时 / 调分 / 调闹钟等） |
| KEY2 | 数值加 |
| KEY3 | 数值减 / 确认 |
| KEY4 | 闹钟开关 / 音乐播放 |

> 请根据实际设计修改按键功能说明。
