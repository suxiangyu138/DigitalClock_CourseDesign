# DigitalClock_CourseDesign

一个数字时钟课程设计项目，实现了基本的时、分、秒报时与时钟设置、闹钟设置、到点报时与闹铃功能，支持时钟分频，并可播放《把回忆拼好给你》的部分音调，最终将时、分、秒显示在 EGO1 开发板上。

> 老师只要求了以上功能，因此未做更多扩展。已有电路稍作调整后即可映射到开发板。
>
> 大二学生的一点小设计，第一次接触硬件，很多地方还不够熟练，大佬勿喷。

---

## 项目简介

本项目是一个面向课程设计的数字时钟，使用 **Logisim Evolution** 搭建电路并完成仿真，通过 **Vivado** 综合并映射到 **EGO1** FPGA 开发板运行。核心功能包括：

- **基本报时**：正常走时并显示时、分、秒
- **时钟设置**：可手动调整当前时间
- **闹钟设置**：可设定闹钟时间
- **到点报时**：到达设定时间触发报时
- **闹铃功能**：闹钟触发时发出提示音
- **时钟分频**：对时钟信号分频，得到所需频率
- **音乐播放**：可播放《把回忆拼好给你》的部分音调
- **数码管显示**：将时、分、秒显示出来
- **FPGA 映射**：在 EGO1 开发板上完成映射与显示

## 工作原理

1. **时钟分频**：将时钟信号分频得到 1Hz 信号，用于秒计数。
2. **计时模块**：秒满 60 进位到分，分满 60 进位到时，时满 24 归零。
3. **显示模块**：将时、分、秒输出到数码管显示。
4. **设置模块**：按键切换设置状态，调整时、分、秒及闹钟值。
5. **闹钟比较**：当前时间与闹钟时间一致时，触发报时与响铃。
6. **音乐播放**：以不同频率驱动蜂鸣器，按预设音符序列播放旋律。

---

## 使用方法

1. 使用 **Logisim Evolution** 打开 `circuit/DigitalClock.circ`，运行仿真。
2. 观察数码管显示，通过按键进行时间与闹钟设置。
3. 使用 **Vivado** 打开工程，针对 EGO1 开发板完成综合、布局布线并下载。
4. 上板后数码管显示当前时间，可测试报时、闹铃与音乐播放功能。
