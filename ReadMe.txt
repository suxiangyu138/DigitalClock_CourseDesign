# DigitalClock_CourseDesign
一个数字时钟课程项目，具有基本的时分秒报时和时钟设置，以及闹钟设置，到点报时，同时具有闹铃功能，时钟分频，可以播放《把回忆拼好给你》这首歌曲的一部分音调，最后可以把基本的时分秒显示起来，因为我们老师只对我们做了这个要求，所以更多的功能我也没做，不过通过已有的电路稍微调整在映射到开发版上，估计也不难。（其实是因为我比较懒）。

开发工具：logisim_evolution  Vivado
开发板型号：EGO1

ps：大二学生的一点小设计，大佬勿喷，第一次做硬件小东西，很多都不是很熟



①基本的时分秒显示
②时钟的时分秒时间设置
③闹铃设置与到点响铃
④自定义闹铃音乐与播放
⑤在EGO开发板上的FPGA映射与显示

设计人员:sangxiangyu cuiguoxuan    Anhui University 2026/4/10
